## Scope not qualified

The workflow tests an explicit reference overlay, not a merged product or tested
merge checkout. It does not run complete unit/backend/build/installed-product
qualification, PostgreSQL, the larger member/lifecycle campaigns, runtime
activation or any provider/release operation. This POSIX retirement composition
uses existing Linux/Darwin owners; it does not claim Windows retirement coverage
or narrow another maintained Windows API's support.

Primitive/API/SQL/VM counts are not OS syscall latency, total process memory or
arbitrary logging/finalizer guarantees. Complete error text and exception graph
inputs are charged, but resource receiving still comes only from original owning
objects. Actual worker join, ordinary withdrawal and semantic retirement remain
independent. A retained unknown may keep capacity occupied under existing policy.
Reference publication cannot certify those predicates by itself.
