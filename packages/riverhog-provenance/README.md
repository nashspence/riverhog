# riverhog-provenance

Canonical journal construction, validation, source observation, exact history
resolution, and delivery verification for Riverhog. Artifacts, occurrences, states,
observations, and contextual locators have distinct identities. A state need not
have a filesystem path.

The schema and semantic rules are in
[`riverhog-provenance-contracts/SPECIFICATION.md`](../riverhog-provenance-contracts/SPECIFICATION.md).
The executable examples and package tests exercise the current contract.
