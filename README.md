# Riverhog release documentation

This independent authoring history supplies prose selected by an exact commit
for release preparation. No product release documentation has been authored yet.

Reviewed versions use `v1.<minor>.<patch>/documentation.json`. Commands, schemas,
defaults, versions and artifact inventories come from the selected code revision's
generator; authored documents contain explanations, guides and stable subject references.

Validate selected commits through the [documentation source check](https://github.com/nashspence/riverhog/blob/main/.github/workflows/documentation-check.yml),
then select their exact SHAs for [release preparation](https://github.com/nashspence/riverhog/blob/main/.github/workflows/release-preparation.yml).
These checks and preparation do not publish. Immutable publication retains the exact
authored bytes alongside the generated record and pinned render.
