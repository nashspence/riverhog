Definition: WriteCompletionPrecondition

object; 3 fields; additionalProperties: false

title
WriteCompletionPrecondition
description
Adapter-issued precondition for one exact active-write state. Consumers echo the opaque token unchanged. It is neither a credential nor a bearer capability; completion remains independently authorized. Once an exact immutable object is published, its completed-object identity supersedes this active-write precondition for terminal reconciliation.
