# Nonnormative reference ecosystem

[Atlas](../../index.md) · [Relationships](../index.md)

Checked-in references form a closed, tightly scoped, maintainer-selected, nonnormative conformance set.

These components exercise maintained boundaries; they do not make their implementation choices authoritative or promise an expanding implementation corpus.
