# Performance objectives

Non-contractual engineering objectives and observations only. These records do not create, extend, interpret, override, or relax any external contract. A recorded target is not automatically a release gate. Related checks retain their independently defined role. No passing execution or external guarantee is implied by this page.

Generated by `python scripts/performance_objectives.py update`; edit the Python definitions, not this page.

## Interpretation

Numerical budgets below are retained engineering tolerances from the inspected main, not newly measured hardware capacities. The 0.90 goodput tolerance is an existing 10% reference deficit allowance, not a scientifically derived optimum. The former nominal 1 Gbit/s baseline is removed. A missing or incompatible reference means not evaluated, never passed.

Goodput is newly completed useful payload divided by the declared complete-operation interval. Compare equal byte domains, workload, completion semantics, direction, environment/path, cache state and concurrency. Raw transport diagnostics are not interchangeable with matched complete-operation references. Keep absolute rates alongside ratios; a ratio is not a physical utilization or bottleneck claim.

A comparison context uses safe fingerprints and a UUID for one explicitly selected measurement session. The checker can validate matching declarations, not independently attest their physical truth. The harness/maintainer owns honest context and completion receipts. No automatic reference rollover is performed.

Every comparison describes its recorded trial only. Repeated runs remain separate observations; there is no invented percentile, representative-population claim or silently selected best trial.

The database two-point guards retain current inequalities and failure behavior. G = high relation rows / low relation rows. Memory figures mean traced Python allocation peaks, not process RSS. Existing correctness, safety and extent checks remain independent.

## Audit boundary

Review newly introduced thresholds when changing benchmark/test code. There is no required test-to-objective link for every unit assertion.
